Usage

How To Use

Add suiVisibility to any element to receive events as it moves through the viewport. Every event receives the element calculations

These examples scroll inside a container passed to suiContext. Leave it out to track scrolling of the whole page.

Changing Callback Frequency

By default each event only fires the first time its condition is met. Set suiOnce to false to fire each time a condition becomes true, or suiContinuous to fire on every scroll while it holds

Call refresh() to reset which events have already fired.

Passed Amounts

suiPassed takes a list of distances, as percentages or pixels, and suiOnPassed fires as each one is scrolled past

Examples

Infinite Scroll

As an alternative to pagination you can use suiOnBottomVisible to load content when the bottom of a container is reached

suiObserveChanges recalculates positions after new content is added.

Lazy Loading Images

Setting suiType to image swaps an image's data-src into its src once its top is visible. Keep a placeholder in src so the layout does not jump when the image loads

Gradual Changes

Each event receives the calculated values, so you can adjust an element as it is scrolled past

Fixing Content To Viewport

Setting suiType to fixed fixes an element to the viewport once its top is passed, adds the class fixed, and inserts a placeholder so the page does not shift. It is unfixed when you scroll back

This example is not run here because this site is wrapped in a sidebar container, and a transformed ancestor stops position: fixed from attaching to the viewport. Use suiZIndex to keep fixed content above the rest of the page.

Methods

Method Description
check() Recalculates and fires any events whose conditions are met
refresh() Resets which events have fired, then checks again
disable() Stops events temporarily, e.g. while you adjust the scroll position
enable() Turns events back on and checks again
