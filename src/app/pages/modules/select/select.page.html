Types

Selection

A standard select can be used to pick between choices in a form.

Search Selection

A selection dropdown can allow a user to search through a large list of choices.

Multiple Selection

A selection dropdown can allow multiple selections.

Selected values are emitted as an array.

Multiple Search Selection

A selection dropdown can allow multiple search selections.

Flag Selection

A selection can include flag icons.

Set flag on an option to the two-letter country code of the flag to show.

Image Selection

A selection can include images.

Forms

Form Binding

A select is a form control. Use it with ngModel, or with formControl / formControlName in reactive forms. The suiSelectionChanged event also fires whenever the selection changes.

Form binding with ngModel and reactive forms requires FormsModule or ReactiveFormsModule. Programmatic value writes are supported for single selection.

States

Loading

A dropdown can show that it is currently loading data.

Error

An errored dropdown can alert a user to a problem.

Disabled

A disabled dropdown menu or item does not allow user interaction.

Variations

Scrolling

A selection dropdown can have its menu scroll.

Compact

A compact selection dropdown has no minimum width.

Import SuiSelectModule from ngx-semantic/modules/select. The select builds its own menu from suiOptions, so you do not need to write menu markup. Looking for a menu of actions? See Dropdown.
