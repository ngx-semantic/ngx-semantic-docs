Static Animations

Static Animations

Jiggle, flash, shake, pulse, tada, bounce and glow draw attention to an element without changing its visibility

Static animations run each time the value bound to suiPlay changes, so increment a counter to replay one.

Usage

Visibility

After an animation finishes, the element keeps its final state. An outward transition leaves it hidden, an inward transition leaves it visible

suiVisible supports two-way binding with [(suiVisible)].

Specifying a Direction

To force an animation direction, add either in or out to the animation name

Without a suffix the direction is chosen automatically: showing an element plays the inward animation and hiding it plays the outward one. You can also force it with suiDirection.

Duration

The duration can be a number of milliseconds or a CSS time string such as 500ms or 2s

Controlling Programmatically

Export the component with #ref="suiTransition" to show, hide, toggle or stop it from the template or a component

Callbacks

A transition reports when an animation starts and completes, and when the element is shown or hidden

Disabled

A disabled transition changes visibility straight away without animating
sui-transition animates with @angular/animations, so your application must enable animations, for example by importing BrowserAnimationsModule or adding provideAnimations().

Methods

Method Description
show() Shows the element with the current animation
hide() Hides the element with the current animation
toggle() Toggles between hidden and visible
setVisible(visible) Shows or hides the element
playStatic() Runs the current animation if it is a static one; does nothing otherwise
stop() Stops the animation that is running
