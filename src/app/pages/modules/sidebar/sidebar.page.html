Types

Sidebar

A sidebar, usually an inverted vertical menu

Bind [(visible)] to show and hide the sidebar. When it is two-way bound, clicking the page content hides the sidebar.

States

Visible

A sidebar can be visible on the page

A sidebar that is not two-way bound stays visible when the page is clicked.

Dimmed

A pusher can be dimmed while the sidebar is visible

Variations

Direction

A sidebar can appear on different sides of the page

Top and bottom sidebars should be horizontal menus, so suiVertical is only set for left and right sidebars.

Width

A sidebar can specify its width

Transitions

A sidebar can use different transitions to appear

uncover, slide along and slide out only support left and right sidebars.

Usage

Page Structure

A sidebar requires a container with a sidebar and a pusher holding the page content

Without suiPushable the page body is the context and the sidebar is fixed to the viewport. Add suiPushable to keep the sidebar inside the container, as in the examples above.
A pushable container cannot have padding.
