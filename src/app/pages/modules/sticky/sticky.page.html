Types

Sticky

Sticky content stays fixed to the viewport while its context is visible

Scroll the page to see the content stick. A sticky is usually placed in a rail, and its suiContext is the element whose bounds it stays within.

Variations

Pushing

Sticky content can push the page up when you scroll back, instead of returning to its original position straight away

Offset

Sticky content can be offset from the top of the viewport, for example to sit below a fixed menu

Events

A sticky element reports when it sticks and unsticks

Scroll Context

A sticky can stick inside a scrolling element instead of the page

suiScrollContext takes a CSS selector for the scrolling element.
