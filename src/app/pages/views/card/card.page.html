Types

Card

A single card.

To ensure cards are equal height use the plural, sui-cards. Card groups automatically use flex styles to match height between cards in the same row.

Cards

A group of cards.

Cards are designed to be flexible to your content. suiCardContent blocks can include any custom elements related to your content.

Content

Content Block

A card can contain blocks of content.

Image

A card can contain an image.

Cards can use reveal or dimmers to easily show additional content, or options on hover.

Header

A card can contain a header.

Metadata

A card can contain content metadata.

You can include an arbitrary amount of metadata using your own class conventions; all child elements will automatically be spaced.

Link

A card can contain links as images, headers, or inside content.

To make the entire content of a card link, check out the link card variation below.

Buttons

A card can contain buttons.

Approval

A card can contain a like or star action.

Description

A card can contain a description with one or more paragraphs.

Extra Content

A card can contain extra content meant to be formatted separately from the main content.

Variations

Fluid Card

A fluid card takes up the width of its container.

Centered Card

A card can center itself inside its container.

Raised Card

A card may be formatted to raise above the page.

Link Card

A card can be formatted so that the entire contents link to another page.

Floated Content

Any content element can be floated left or right.

You can include an arbitrary amount of metadata using your own class conventions; all child elements will automatically be spaced.

Text Alignment

Any element inside a card can have its text alignment specified.

Coloured

A card can specify a colour.

Column Count

A group of cards can set how many cards should exist in a row.

Stackable

A group of cards can automatically stack rows to a single column on mobile devices.

Resize your browser to a smaller size to see the cards stack after reaching mobile breakpoints.

Doubling

A group of cards can double its column width for mobile.

Resize your browser to a smaller size to see the cards stack after reaching mobile breakpoints.

Import SuiCardModule from ngx-semantic/views/card to use every directive documented below. Each directive is also standalone and can be imported on its own.
