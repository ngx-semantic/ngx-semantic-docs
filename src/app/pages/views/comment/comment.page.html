Types

Comments

A basic list of comments.

The Semantic UI examples often wrap content in ui segment; that is optional. UI views provide structured layouts but do not wire up site-specific behavior. You will need your own logic to show or hide reply forms—for example, when the user clicks Reply.

Content

Comment

Avatar

A comment can contain an image or avatar.

Metadata

A comment can contain metadata about the comment; you may add any number of metadata items.

Actions

A comment can contain actions the user may perform related to this comment.

Reply form

A comment can contain a form to reply to a comment. Content can be arbitrary. If a comment form is inside a ui comment, it is styled as a nested reply form. If the form appears after all comments, it is styled as a normal reply form.

States

Collapsed

Comments can be collapsed, or hidden from view.

Variations

Threaded

A comment list can be threaded to show the relationship between conversations.

Minimal

Comments can hide extra information unless a user shows intent to interact with a comment.

Size

Comments can have different sizes.
